Anthropic models: Claude Code vs GitHub Copilot

Data verified 14 November 2026. Report prepared 15 November 2026. This is a dated snapshot, not a live catalog.

Scope: Claude Code connected directly to Anthropic versus the GitHub Copilot model catalog. Claude Code through LiteLLM and Copilot is a third case, constrained by both Copilot and the gateway configuration.

Bottom line: both offer the latest four models. The main differences are fast-mode availability, client-specific context and effort controls, billing, and retirement policies.

GitHub confirms configurable reasoning but does not publish an exact per-model tier/default matrix in its public model reference. The choices exposed by a particular Copilot client are authoritative. Identical effort support through this LiteLLM route has not been verified.

Copilot CLI 1.0.108 documents --reasoning-effort values none, minimal, low, medium, high, xhigh, max, subject to model support. --context default|long_context and /model select eligible context tiers. This is not proof that every model supports every value.

Current Claude Code cannot disable thinking on Fable, Opus 5.5, Sonnet 5.5 or Haiku 5.5. Older explicit thinking-budget controls are not interchangeable with adaptive effort.

Gateway implications and policy

This project's default is Sonnet 5.5. Fable 5.2 is mapped as a selectable option only. This differs from Anthropic's own Claude Code default, Opus 5.5, shown above.

Observed deployment snapshot, 14 November 2026: Opus 5.5, Sonnet 5.5, Sonnet 5, Haiku 5.5 and Haiku 4.5 were exposed to the evaluated personal gateway key. Fable 5.2 was available upstream but was not in that live catalog. This is historical evidence, not a claim about every deployment or future configuration.

Parity remains unverified: 1M requests, every effort level and paid fast mode were not verified end-to-end through LiteLLM. Model discovery alone does not prove those capabilities.

Fable policy: prompts and outputs are retained by default for safety classifiers, not model training. Copilot's Fable policy defaults to off and requires explicit admin enablement. Eligible enterprises can request a ZDR (zero data retention) exemption through the end of 2026 via their GitHub account team, pending Enterprise Frontier Safeguards. Exemption use is internal-only; approval does not itself enable the model. Other Claude models in Copilot continue under ZDR. [10]
