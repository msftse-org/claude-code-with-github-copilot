LiteLLM's role

Claude Code sends the native Anthropic Messages API to LiteLLM. CCGC authentication resolves the employee credential to that employee's LiteLLM virtual key and encrypted GitHub OAuth connection. LiteLLM's built-in GitHub Copilot provider calls GitHub Copilot's HTTPS /v1/messages API with the employee's Copilot authorization and streams SSE back. This is an API integration, not a GitHub SDK, with no direct Anthropic API key and no shared Copilot seat.

Administration layer

The control plane handles Entra-authorized enrollment, immutable Entra-to-GitHub binding, revocation, admissions, Key Vault references, and LiteLLM user/model reconciliation. It supports the runtime but never proxies prompt or response bodies.
